# defect_inspector — інспекція деталей на дефекти

Промисловий застосунок комп'ютерного зору для автоматичного виявлення
поверхневих дефектів деталей. Працює **офлайн**, не потребує датасету та
навчання, має CLI, конфігурацію порогів, звіти (JSON + анотовані
зображення) і набір тестів.

## Які дефекти виявляє

| Детектор | Тип дефекту | Метод |
|----------|-------------|-------|
| `scratch` | подряпини, тріщини, волосовини | ridge-фільтр Sato + аналіз елонгації (повернутий прямокутник) |
| `spot` | плями, забруднення, раковини, точкові дефекти | відхилення від локального фону + фільтр за площею/округлістю |
| `edge` | сколи, вищербини по контуру | дефекти опуклості силуету деталі |
| `reference` | будь-які відхилення від еталона | вирівнювання (ORB+гомографія) і різниця з golden sample |

Поверхневі детектори працюють лише в межах деталі (ROI-маска), тож фон і
край силуету не дають хибних спрацювань.

## Встановлення

```bash
pip install -r defect_inspector/requirements.txt
```

## Швидкий старт — демонстрація

Згенерувати синтетичні зразки (годна + дефектна деталь) і перевірити їх:

```bash
python -m defect_inspector demo --out demo_out
```

У `demo_out/` з'являться зразки, анотовані зображення та JSON-звіти.

## Використання

```bash
# одне зображення (reference-free)
python -m defect_inspector inspect part.jpg --out out

# порівняння з еталоном (надійніше для деталей зі складною геометрією)
python -m defect_inspector inspect part.jpg --reference good.jpg --out out

# пакетна перевірка цілого каталогу
python -m defect_inspector batch ./images --out out

# згенерувати конфіг порогів за замовчуванням і відредагувати під свою деталь
python -m defect_inspector init-config config.json
python -m defect_inspector --config config.json inspect part.jpg --out out
```

Код виходу: `0` — PASS, `2` — FAIL, `1` — помилка. Зручно для конвеєрів /
CI та інтеграції з ПЛК через обгортку.

## Програмний інтерфейс

```python
from defect_inspector import Inspector, InspectionConfig

inspector = Inspector(InspectionConfig())          # або .from_file("config.json")
result = inspector.inspect("part.jpg", reference="good.jpg")

print(result.verdict)          # "PASS" / "FAIL"
for d in result.defects:
    print(d.kind, d.severity, d.bbox)
```

## Два режими роботи

* **Reference-free** — придатний для відносно однорідної поверхні без
  навмисних елементів. Знаходить подряпини, плями та сколи без еталона.
* **Reference (golden sample)** — рекомендований для деталей з отворами,
  гравіруванням, складною геометрією: будь-яке відхилення від годного
  зразка трактується як дефект, навмисні елементи не дають хибних спрацювань.

## Конфігурація

Усі пороги зібрані в `config.py` (dataclass-и) і можуть завантажуватись з
JSON. Ключові параметри вердикту (`VerdictConfig`):

* `min_severity` — мінімальна тяжкість, щоб дефект враховувався;
* `fail_severity` — тяжкість, за якої деталь бракується;
* `max_defect_count` — допустима кількість дефектів;
* `max_area_ratio` — допустима частка площі дефектів.

## Архітектура й розширення

```
defect_inspector/
├── config.py          # пороги (dataclass + JSON)
├── image_io.py        # завантаження, препроцесинг, ROI-маска
├── detectors/         # незалежні детектори зі спільним інтерфейсом
│   ├── base.py        # Detector (ABC), Defect
│   ├── scratch.py  spot.py  edge.py  reference.py
├── pipeline.py        # Inspector: запуск детекторів, NMS, вердикт
├── report.py          # JSON + анотоване зображення
├── samples.py         # синтетичні зразки для демо/тестів
├── cli.py / __main__  # CLI
└── tests/             # pytest
```

Щоб додати новий детектор (зокрема нейромережевий), достатньо реалізувати
інтерфейс `detectors.base.Detector` і підключити його в `pipeline.Inspector`.

## Тести

```bash
python -m pytest defect_inspector/tests/ -q
```

## Обмеження

* Reference-free режим розрахований на відносно рівномірну поверхню;
  навмисні елементи (отвори, маркування) краще контролювати в reference-режимі.
* Якість залежить від стабільності освітлення та ракурсу зйомки.
* Для тонких специфічних промислових дефектів найвищу точність дає
  навчена нейромережа — її можна підключити як ще один детектор.
